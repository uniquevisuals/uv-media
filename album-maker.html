Create a New Album

Fill the details, click Generate, then follow the 3 upload steps below. The customer gets one link.

Upload Steps (GitHub)

  1. Photos: In the repo, Add file → Create new file → name it photos/ALBUM-ID/.gitkeep → Commit. Then open that folder → Add file → Upload files → upload front.jpg (front cover), back.jpg (back cover) and all sheet photos → Commit.
  2. Album file: Open the albums folder → Add file → Upload files → upload the downloaded ALBUM-ID.js → Commit.
  3. Share: Send the customer link to the customer. Done!

Use the sharp (3600px) photo copies for best clarity. Sheet names must match the style you picked above.
